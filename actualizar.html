1Conexión con GitHub

Solo se configura una vez en esta computadora. La clave se guarda en este navegador y no se sube a ningún lado.

¿Cómo saco la clave de GitHub?
  1. En GitHub, da clic en tu foto (arriba a la derecha) → Settings.
  2. Hasta abajo del menú izquierdo: Developer settings → Personal access tokens → Fine-grained tokens.
  3. Da clic en Generate new token. En Token name escribe Tablero DDS y en Expiration elige la fecha más lejana que te permita.
  4. En Repository access elige Only select repositories y selecciona tu repositorio del tablero.
  5. En Permissions → Repository permissions, busca Contents y cámbialo a Read and write.
  6. Da clic en Generate token, copia la clave (empieza con github_pat_) y pégala aquí. GitHub solo la muestra una vez.
